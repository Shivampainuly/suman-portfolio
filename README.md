# Suman Painuly — Endpoint Engineering Portfolio

A Next.js 14 + TypeScript portfolio for Endpoint Engineering, Microsoft Intune, SCCM, automation, and platform operations.

## Visual direction

Warm old-money editorial aesthetic: ivory, parchment, espresso, forest green, and antique brass. The application remains a real Next.js project with React components and interactive behavior — it is not a flattened HTML export.

## Routes

- `/` — Home
- `/experience` — Experience
- `/engineering` — Engineering projects
- `/skills` — Skills
- `/lab` — Lab / automation
- `/contact` — Contact

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
```

## GitHub Pages

The repository includes a GitHub Actions workflow that exports the Next.js application and deploys the `out` directory to GitHub Pages. The production URL is expected at:

https://shivampainuly.github.io/suman-portfolio/
